# rintrint

Tools developer working at the intersection of MMD, Blender, and Unreal Engine.

## What I work on

- **[MMD Tools](https://github.com/MMD-Blender/blender_mmd_tools)** — Blender addon for the MikuMikuDance ecosystem. Currently maintaining.
- **[MMDBridge](https://github.com/rintrint/mmdbridge)** — D3D9 hook that exports MMD render data to external pipelines (Alembic, VMD).
- **[IVP5U](https://github.com/rintrint/IVP5U)** — Unreal Engine 5 plugin for importing PMX models and VMD animations.
- **[KKBridge](https://github.com/rintrint/KKBridge)** — BepInEx plugin that exports Koikatsu Timeline animations to VMD.

## Interests

3D character pipelines, cross-engine tooling, real-time rendering, anime-style shading.

Languages: 中文 / English / 日本語
