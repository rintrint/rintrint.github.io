# 海豹呼呼：上岸的一口氣

獨立 HTML 場景提案，不修改 Unity V15.0.0 或既有十三版。

- A 破冰衝刺：單拍破冰、明確的撞飛拋物線，適合常規小換氣。
- B 拉線拔河：第 2、3、4 拍拉線，水面與水下同框，適合角色互動。
- C 深吸大躍：水下推近、撞擊慢動作、喘息特寫、跨洞大跳，適合重要關卡段落。

點「觀看演出」即可看完整成功路線；「親自試玩」使用 Space 或下方動作按鈕。跟拍上岸、限時連打補氣，再跟大吸氣後的重拍跳到下一個洞。Esc 暫停，R 重播。切換到其他分頁會自動暫停。

這是約 16 秒的演出比較片段，以原創 120 BPM 音型與四拍提示音示範，並使用專案既有的出水、撞倒垂釣者、吸氣與落水音效；不是三首正式歌曲的新譜面。飽食度暫時固定在進入冰洞時的 110/120，用於比較換氣段落。

新美術 `assets/fisher-poses.png` 由內建 imagegen 生成（垂釣者三姿勢、冰洞、魚竿、雪花），以既有 fisherman 及海豹為風格參考。其餘圖與音效使用 `../assets`，需透過 HTTP 伺服器開啟。完整生成提示見 `ART-PROMPT.txt`。

本機：從 `gamejam` 執行 `node server.cjs`，開啟 `/shore-lab/index.html`。測試：在本資料夾執行 `node --test core.test.js`。

角色採原圖比例，撞飛與魚竿分開計算拋物線；原始素材不被覆蓋。自動演出、手動成功／失敗、暫停、補氣遞減及持續耗氧皆有規則測試。
