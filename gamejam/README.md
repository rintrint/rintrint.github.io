# Breath — 冰隙之間

一隻飢餓的小海豹，靠著呼吸、音樂與冰洞穿過冰海。可玩的 **2D 繪本版 / 3D 光影版** 共用相同旅程與判定，方便比較美術風格。

## 執行

安裝 Node.js 後，在此目錄執行 `node server.cjs` 或 `npm start`。兩版均使用 ES modules，請透過 HTTP 開啟，不能直接雙擊 HTML。

- [2D 繪本](http://127.0.0.1:4173/index.html)
- [3D 光影](http://127.0.0.1:4173/3d.html)
- [同場景美術對照](http://127.0.0.1:4173/art-review.html)：開場、游泳、冰洞、跳躍、結局；這是獨立展示頁，不會修改遊戲進度。

不需安裝 npm 套件或建置。Three.js 0.180.0 與 MIT 授權存於 `vendor/`。3D 需要 WebGL 2。圖片與程式都在本機；Google Fonts 載入失敗時使用系統字型。

## 玩法

- **WASD / 方向鍵**：水下游動，靠近魚就會吃下；深處的魚提供更多飽足，也更耗氧。
- **按住 SPACE、準拍放開**：吸氣與動作。音樂為 72 BPM，每四拍一個呼吸樂句；明亮琴音、海水和光束共同提示樂句開頭，不需盯著判定圈。
- **E**：結尾上岸後呼喚同伴。
- **Esc**：暫停 / 繼續；離開視窗或切換分頁自動暫停。
- **音樂**：點開始後啟動原創合成配樂，可隨時靜音。下潛時高頻逐漸柔化；吃魚、水花、換氣與跨洞跳躍有獨立聲音。
- 也可以點「吸氣」開始、再點「放開」完成；手機提供方向按鈕。兩版採相同平面移動規則，3D 提供立體景深與視角切換。切換版本重新開始。

旅程依序為：

1. 扁扁的小海豹躺在冰上。完成兩次至少一秒的準拍呼吸，吸滿一口氣。
2. 再次準拍放開，穿過第一道冰縫下海。
3. 吃魚，游向第一位釣魚人的光束。靠近洞口、準拍放開才能躍出，撞倒釣魚人；換一小口氣，再準拍入水。
4. 在第二個釣魚洞上岸，長吸至少兩秒、準拍放開，伴隨大吸氣聲跳向下一個洞。未成功就不能進入結局，可以留在岸上重試。
5. 累積至少 12 份小魚，在最後的冰洞準拍上岸，呼喚新朋友。

普通冰層不能穿過或換氣。水下準拍可獲得省氧加速，不會憑空補氧。氧氣歸零會窒息、結束本次旅程，可重新開始。呼吸是按鍵機制，玩家保持自然呼吸即可。

## 實作與素材

- `journey-core.js`：共用、可測試的節奏與故事狀態機。
- `journey.js` / `journey.css`：輸入、介面、事件與畫面更新。
- `journey-audio.js`：Web Audio 原創和弦、旋律與聲音合成；音樂與視覺使用同一個遊戲時鐘。
- `journey-view2d.js`：繪本背景、海豹素材動畫、魚群、水花與光束。
- `journey-view3d.js`：立體海豹與釣魚人、冰層、海草、動態水面、海底焦散及粒子。
- `assets/glacier-world.png` / `assets/seal.png`：使用內建 image_gen 生成，海豹保留透明 alpha；完整提示詞與來源記錄於 `assets/art-prompts.json`。

舊版 `game-core.js`、`game.js`、`scene3d.js`、`3d-loader.js`、`style.css`、`3d.css` 保留供原型回顧，目前入口沒有載入它們。

執行 `node --test`：包含舊原型 13 項測試，共 22 項。瀏覽器另驗證實際按鈕呼吸、氧氣補滿、入水、暫停、兩版載入與不同尺寸畫面。美術對照頁的展示狀態不作為遊戲通關測試。
