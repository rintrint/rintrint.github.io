# Breath — 冰隙之間

一隻飢餓的小海豹，靠著呼吸、音樂與冰洞穿過冰海。頂部依序提供七個編號版本：**1. 2D 繪本 / 2. 3D 光影 / 3. 圈圈節奏 / 4. 海豹上下 / 5. 手繪海豹 / 6. 呼吸旅程 / 7. 雙軌對照**。前六版保留；第七版用指定 MUSE DASH 影片的音源與重建譜面，對照雙軌節奏操作。

## 執行

安裝 Node.js 後，在此目錄執行 `node server.cjs` 或 `npm start`。所有版本均使用 ES modules，請透過 HTTP 開啟，不能直接雙擊 HTML。

- [2D 繪本](http://127.0.0.1:4173/index.html)
- [3D 光影](http://127.0.0.1:4173/3d.html)
- [圈圈節奏](http://127.0.0.1:4173/rings.html)：光環縮到小圈時按 SPACE。
- [海豹上下](http://127.0.0.1:4173/runner.html)：魚群抵達海豹面前時按 SPACE 躍起，角色位置固定，場景持續捲動。
- [手繪海豹](http://127.0.0.1:4173/sketch.html)：獨立第五版，沿用上下跳躍玩法，使用使用者海豹概念圖衍生的粉彩鉛筆美術。
- [呼吸旅程](http://127.0.0.1:4173/tide.html)：獨立第六版，實際起音譜面、輸出延遲補償、拍點試聽校正；蓄氣、冰洞換氣、必要跨洞，三階段 438 隻魚。完整規則與音樂分析方法見 [第六版設計核對](JOURNEY-DESIGN.md)。
- [雙軌對照](http://127.0.0.1:4173/dash.html)：獨立第七版，《草蛇驚一》影片音源，固定 514 判定；上下雙軌、15 段長按、2 段連打、冰刺避障。提供自動演示與延遲校準；影片轉錄精度與玩法差異見 [第七版對照說明](DASH-REFERENCE.md)。
- [同場景美術對照](http://127.0.0.1:4173/art-review.html)：開場、游泳、冰洞、跳躍、結局；這是獨立展示頁，不會修改遊戲進度。

不需安裝 npm 套件或建置。Three.js 0.180.0 與 MIT 授權存於 `vendor/`。3D 需要 WebGL 2。圖片與程式都在本機；Google Fonts 載入失敗時使用系統字型。

## 玩法

### 三個音樂版本與難度

三版皆可選擇使用者提供的 **Oceanic Wash / Oceanic Wash 2**，長度均約 3:39。圈圈版預選第一首，兩個海豹版預選第二首。按「開始聽海」後倒數，整首播放；所有難度維持原速。首次進入預選新手，之後記住難度選擇。

| 難度 | 第一首／第二首拍數 | 節奏編排 | Perfect／Good／Soft 判定 | 光圈提前出現 | 漏拍扣能量 |
| --- | --- | --- | --- | --- | --- |
| 新手 | 111／111 | 稀疏單拍、樂句間休息 | ±100／170／240 ms | 2.4 秒 | 4 |
| 中階 | 252／252 | 連續單拍，部分樂句加反拍 | ±75／135／190 ms | 1.75 秒 | 6 |
| 高手 | 521／522 | 八分音符連打、短十六分音符快拍 | ±45／85／130 ms | 1.15 秒 | 8 |

海豹版的場景接近速度為中階的 0.8／1／1.4 倍，音樂速度不變。兩個海豹版共用持續運算的高度、速度、重力與彈性形變：準拍以短促力道推進現有動作，空拍不會重設動畫；密集連打的加力受限，不會無限上升。回到基準面時有壓縮回彈、水波、接觸陰影及輕音效。計分倍率為 0.8／1／1.3；練習另行標示。

- SPACE 或右下觸控按鈕：單次按下判定，不需按住或方向鍵。長按不會重複計分。
- 練習模式在所選難度的最外判定額外放寬 50 ms，保留該難度的譜面。
- 命中會吃魚、逐漸長大、累積連擊和分數，並發出水光、粒子與輕音效。漏拍減少呼吸能量，低於 35% 畫面逐漸變暗並警示；命中回補能量。
- 圈圈內的小魚就是命中目標。命中後小魚沿弧線飛到嘴邊，吞食後才顯示「吃到魚 +1」、肚子鼓起與平滑長大；介面同步顯示體型百分比。正式譜面吃到 12／24 隻時成長一階，最大體型 145%，不再把明顯成長拖到歌曲後半。兩個海豹版也使用吞食與身體回饋。
- 跳躍與吞食以歌曲時鐘驅動，暫停會凍結位置與吞食進度；不使用停止音樂的命中停頓。視覺以局部水波和短水跡取代多張海豹殘影，降低全畫面閃光。
- 輕鬆練習不會失敗。普通模式能量歸零結束；歌曲完整結束才能與朋友相遇，顯示準確率、最高連擊和分數。
- Esc / 暫停鈕：停止歌曲與判定，續播接回同一位置。離開視窗自動暫停。
- 選曲頁提供 ±200 ms 延遲校正並記住設定。若按到聽見的拍點總被判晚，調整為正值。
- 光線隨實際音樂音量和拍點呼吸；旅程從晨光、深藍到極光，包含景深粒子、魚群、海草、殘影與冰台。

`rhythm-core.js` 管理規則，`rhythm-audio.js` 用 Web Audio 播放原始 MP3，`rhythm-view.js` 繪製圈圈與原海豹版，`rhythm-view-sketch.js` 獨立提供手繪美術。播放、移動和判定共用 AudioContext 時鐘，避免逐幀累積誤差。`assets/music-charts.json` 儲存每首歌曲的三套譜面，以不同樂句節奏編排後貼近音訊起音，可再手工微調。要重建，依序執行 `tools/analyze_tracks.py` 和 `tools/build_difficulty_charts.py`，需要 Python numpy、scipy、soundfile；遊玩不需要 Python。

第五版的海豹 `assets/sketch/seal.png`、背景 `assets/sketch/ocean.png`、冰台／魚群／植物圖集 `assets/sketch/props.png` 均由內建 image_gen 依使用者提供的 `IMG_4306.webp` 生成。海豹與圖集保留真正 alpha 透明度；圖集直接由 Canvas 取樣繪製。完整提示詞存於 `assets/sketch/prompts.json`。原本海豹上下版的素材與入口保留。

新背景 `assets/rhythm-ocean.png` 使用內建 image_gen 生成，提示詞記錄於 `assets/rhythm-art-prompt.json`。使用者提供的兩首音樂存於 `assets/audio/`，未替換原版合成配樂。使用者提供的短片僅作為固定角色與移動場景的動作參考；未將影片或 [Melatonin](https://store.steampowered.com/app/1585220/Melatonin/) 的美術素材放入遊戲。

所有遊戲資源採相對路徑，可部署在 GitHub Pages 的 `/gamejam/` 子目錄。主要修改目錄為 `rintrint.github.io/gamejam/`。

### 原版 2D / 3D 呼吸旅程

- **WASD / 方向鍵**：水下游動，靠近魚就會吃下；深處的魚提供更多飽足，也更耗氧。
- **按住 SPACE、準拍放開**：吸氣與動作。音樂為 72 BPM，每四拍一個呼吸樂句；明亮琴音、海水和光束共同提示樂句開頭，不需盯著判定圈。
- **E**：結尾上岸後呼喚同伴。
- **Esc**：暫停 / 繼續；離開視窗或切換分頁自動暫停。
- **音樂**：點開始後啟動原創合成配樂，可隨時靜音。下潛時高頻逐漸柔化；吃魚、水花、換氣與跨洞跳躍有獨立聲音。
- 也可以點「吸氣」開始、再點「放開」完成；手機提供方向按鈕。兩版採相同平面移動規則，3D 提供立體景深與視角切換。切換版本重新開始。

旅程依序為：

1. 扁扁的小海豹躺在冰上。完成兩次至少一秒的準拍呼吸，吸滿一口氣。
2. 再次準拍放開，穿過第一道冰縫下海。
3. 吃魚，游向第一位釣魚人的光束。靠近洞口、準拍放開才能躍出，撞倒釣魚人；換一小口氣，再準拍入水。
4. 在第二個釣魚洞上岸，長吸至少兩秒、準拍放開，伴隨大吸氣聲跳向下一個洞。未成功就不能進入結局，可以留在岸上重試。
5. 累積至少 12 份小魚，在最後的冰洞準拍上岸，呼喚新朋友。

普通冰層不能穿過或換氣。水下準拍可獲得省氧加速，不會憑空補氧。氧氣歸零會窒息、結束本次旅程，可重新開始。呼吸是按鍵機制，玩家保持自然呼吸即可。

## 實作與素材

- `journey-core.js`：共用、可測試的節奏與故事狀態機。
- `journey.js` / `journey.css`：輸入、介面、事件與畫面更新。
- `journey-audio.js`：Web Audio 原創和弦、旋律與聲音合成；音樂與視覺使用同一個遊戲時鐘。
- `journey-view2d.js`：繪本背景、海豹素材動畫、魚群、水花與光束。
- `journey-view3d.js`：立體海豹與釣魚人、冰層、海草、動態水面、海底焦散及粒子。
- `assets/glacier-world.png` / `assets/seal.png`：使用內建 image_gen 生成，海豹保留透明 alpha；完整提示詞與來源記錄於 `assets/art-prompts.json`。

舊版 `game-core.js`、`game.js`、`scene3d.js`、`3d-loader.js`、`style.css`、`3d.css` 保留供原型回顧，目前入口沒有載入它們。

## 手動錄拍工具

`beat-recorder.html`：選 Oceanic Wash 或 Oceanic Wash 2，播放後按 SPACE／點大按鈕，每次記下歌曲的實際輸出時間。可暫停續錄、撤銷上一拍，每首歌獨立自動暫存。下載為 `Oceanic-Wash-beats.txt` 或 `Oceanic-Wash-2-beats.txt`；每行只有一個秒數，三位小數、無標題、無序號、不自動吸附拍點，例如 `12.345`。人工反應時間保留在錄製結果中，未擅自校正。第六版選曲頁有工具入口；這是編譜工具，不是第七版遊戲。
