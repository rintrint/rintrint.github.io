rin attack — 影片時長 × 抽幀方法 比較

同一套 prompt + 起始幀,Grok Imagine 生成 4s / 2s / 1s(24fps 固定)。 0.5s 不存在:API 的 duration 只收整數秒、最小 1s(實測 0.5 / "0.5" / "0.5s" 皆 HTTP 422)。 方法 A = 原生 24fps 全幀 + 加速播放;方法 B = 12fps 全抽 + 加速播放;方法 C = 直接稀疏抽 ~12 幀。 所有格子都循環播放同一個「動作總時長」(下方滑桿),所以差異只剩:幀數平滑度 × 影片本身的動作編排。
建議在 0.5–1.2s 之間找攻擊手感
